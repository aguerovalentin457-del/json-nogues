Feriados Nacionales de Argentina 2026

Descripción: Este JSON contiene el calendario oficial de feriados de Argentina para 2026. Organiza cronológicamente los días no laborables del año, agrupándolos por mes. Cada registro entrega tres datos clave de forma estructurada: la fecha exacta (en formato ISO), el nombre oficial del evento histórico o religioso, y su clasificación legal. Esta última divide los feriados en "inamovibles", "trasladables" (fechas que se mueven) y "puente" (fines de semana largos turísticos). Es una base de datos limpia y lista para programar agendas, sistemas de recursos humanos o aplicaciones de turismo en el país.
